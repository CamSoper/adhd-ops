# Focus audio — tunable rulebook

How the audio piece of /gsd's Step 7 **ritual offer** works. The audio never rides alone -- it's
one piece of the single bundled "want the full ritual?" yes. This file is meant to be edited:
change the rules or add taste notes here and the skill behaves differently next run, no code
change needed.

## The offer

- **One pick, based on the user's tastes.** Use the taste notes below, anything they've said in
  conversation, and a currently-playing check if a music connector is in the session (in which
  case the offer is usually "keep it rolling" or nothing at all).
- Deliver a **one-tap link** via whatever music service is connected. If the connector can start
  playback directly, offer to just start it.
- **One offer, no follow-up sell.** Declined or ignored = dropped. The audio is a runway assist,
  not a second decision to burden the rescue moment with.

## Hard rule: no audiobooks

Narrative audio competes for the same attention channel as focused work -- the user ends up
rewinding, frustrated that they have no idea what's going on. That's an architecture problem, not
a willpower problem, so audiobooks are excluded from /gsd offers entirely. If the user asks for
one anyway, say why it's excluded and point at their audiobook app -- don't improvise an
integration mid-rescue.

mood for -- one question max.
